# Software Engineering 2

Dieses Verzeichnis enthält fortgeschrittene Projekte aus dem Kurs Software Engineering 2. Der Schwerpunkt liegt auf komplexeren Webanwendungen und akademischer Dokumentation.

## Projekte

### SWE2_Projekt
Ein größeres Webprojekt, das verschiedene Aspekte der Softwareentwicklung integriert. Dieses Projekt demonstriert die Anwendung fortgeschrittener Konzepte in einer praktischen Umgebung.

### vorlageSWE.tex
Eine LaTeX-Vorlage für akademische Dokumentation im Rahmen von Software Engineering Projekten. Diese Vorlage dient als Grundlage für technische Berichte und Projektdokumentationen.

## Lernziele

- Entwicklung komplexer Webanwendungen
- Akademisches Schreiben und Dokumentation
- LaTeX für technische Dokumente
- Integration verschiedener Softwarekomponenten

## Technologien

- HTML/CSS
- LaTeX
- Verschiedene Web-Frameworks
