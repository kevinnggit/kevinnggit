# TFW - Theoretische Grundlagen der Webentwicklung

Dieses Verzeichnis enthält Projekte und Übungen aus dem Kurs "Theoretische Foundations of Web Engineering". Der Fokus liegt auf serverseitiger Programmierung und CGI.

## Struktur

### cgi
CGI-Skripte (Common Gateway Interface) für serverseitige Webprogrammierung. Diese Skripte demonstrieren die Kommunikation zwischen Webserver und Backend.

### html
HTML-Dateien und Templates für die TFW-Projekte.

## Lernziele

- Verständnis von Client-Server-Architektur
- Serverseitige Programmierung mit CGI
- Webserver-Konfiguration
- Dynamische Webseiten-Generierung

## Technologien

- CGI (Common Gateway Interface)
- HTML
- Bash/Shell-Scripting für CGI
