# CSS & Webentwicklung

Dieses Verzeichnis enthält CSS-Dateien und Stylesheets für verschiedene Webprojekte. Die Styles sind Teil der SWE-Projekte und demonstrieren moderne CSS-Praktiken.

## Dateien

- `index.css` - Stylesheet für die Startseite
- `login.css` - Styling für das Login-Formular
- `register.css` - Styling für die Registrierungsseite
- `forget.css` - Styling für die Passwort-Wiederherstellung
- `main-page.css` - Styling für die Hauptseite
- `style.css` - Allgemeine Stylesheet-Definitionen

## Konzepte

Die CSS-Dateien demonstrieren:
- Responsives Design
- Formular-Styling
- Konsistente Farbschemata
- Layout-Techniken

## Verwendung

Diese Stylesheets gehören zu den HTML-Seiten im SWE1-Verzeichnis und sollten zusammen mit diesen verwendet werden.
