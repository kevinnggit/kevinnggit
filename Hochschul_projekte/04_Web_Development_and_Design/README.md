## Beschreibung
Dieses Modul konzentriert sich auf das **Frontend-Engineering** und das Design von Benutzeroberflächen. Es umfasst sowohl praktische CSS-Projekte als auch theoretische Grundlagen.

## Inhalte

- **CSS_Projects/**: Praktische Anwendungen von CSS3. Hier finden sich Layout-Experimente, Responsive Design Übungen und Styling-Komponenten. (`CSS_Webentwicklung`)
- **Theoretical_Foundations/**: Theoretische Arbeiten und Konzepte (`TFW` - theoretische Fachwissenschaft? / Theorie Web). Hier werden Prinzipien wie Usability, Accessibility und Web-Standards behandelt.

## Technologien
- **HTML5**: Semantische Strukturierung.
- **CSS3**: Flexbox, Grid, Animationen und Media Queries.
- **JavaScript**: (Optional) Für interaktive Elemente.
