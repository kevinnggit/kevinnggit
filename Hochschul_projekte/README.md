# Hochschul-Projekte

Dieses Repository enthält eine kuratierte Sammlung meiner akademischen Projekte und Übungen aus verschiedenen Kursen meines Informatikstudiums. Die Projekte wurden professionell reorganisiert, um meinen Lernfortschritt und meine technischen Fähigkeiten in verschiedenen Fachbereichen zu demonstrieren.

## Struktur

Die Projekte sind in 5 Hauptmodule unterteilt, die jeweils einen spezifischen akademischen Bereich abdecken:

### [01_Software_Engineering_1](./01_Software_Engineering_1)
Grundlegende Konzepte der modernen Softwareentwicklung.
- **Inhalte:** Web Engineering Basics, Bash Scripting, Versionskontrolle (Git).
- **Technologien:** Shell, HTML5, CSS3.

### [02_Software_Engineering_2](./02_Software_Engineering_2)
Fortgeschrittene Entwicklungsmethoden und Softwarearchitektur.
- **Inhalte:** Software-Design-Patterns, Technische Dokumentation (LaTeX), komplexere Web-Anwendungen.
- **Technologien:** Java, Python, LaTeX.

### [03_Programming_Java](./03_Programming_Java)
Objektorientierte Programmierung und Algorithmik.
- **Inhalte:** OOP-Konzepte (Vererbung, Polymorphie), Algorithmen, Spielentwicklung ("Schiffe Versenken").
- **Technologien:** Java (JDK 8+).

### [04_Web_Development_and_Design](./04_Web_Development_and_Design)
Frontend-Engineering und User Interface Design.
- **Inhalte:** Responsive Design, CSS-Architektur, Theoretische Grundlagen (Usability, Accessibility).
- **Technologien:** CSS3 (Flexbox/Grid), HTML5.

### [05_Data_Science_and_Stats](./05_Data_Science_and_Stats)
Datenanalyse und statistische Modellierung.
- **Inhalte:** Verteilungsanalysen, Hypothesentests, Datenvisualisierung.
- **Technologien:** Python (NumPy, SciPy, Matplotlib), R, Jupyter Notebooks.

---

### [99_Archive](./99_Archive)
Enthält ältere Versionen, Duplikate und miscellaneous Dateien, die für aktuelle Projekte nicht mehr relevant sind, aber zu Archivzwecken aufbewahrt werden.

## Nutzung

Jedes Modulverzeichnis enthält eine eigene, detaillierte `README.md` (auf Deutsch), die spezifische Informationen zu den enthaltenen Projekten, Installationsanweisungen und technischen Details bietet.
