# Hochschul-Projekte

Dieses Repository enthält eine Sammlung meiner akademischen Projekte und Übungen aus verschiedenen Kursen meines Informatikstudiums. Die Projekte sind thematisch nach Modulen organisiert und dokumentieren meinen Lernfortschritt sowie praktische Anwendungen verschiedener Technologien und Konzepte.

## Struktur

### SWE1 - Software Engineering 1
Grundlegende Konzepte der Softwareentwicklung, einschließlich Bash-Scripting, Versionskontrolle und strukturierter Programmierung.

### SWE2 - Software Engineering 2
Fortgeschrittene Softwareentwicklung mit Fokus auf Webentwicklung, Dokumentation und größere Projekte.

### Programmierung
Verschiedene Programmierprojekte in Java und anderen Sprachen, darunter objektorientierte Programmierung und praktische Anwendungen.

### CSS & Webentwicklung
Projekte zur Frontend-Entwicklung mit HTML, CSS und verwandten Technologien.

### TFW - Theoretische Foundations of Web Engineering
Theoretische Grundlagen und praktische Übungen zur Webentwicklung.

### Sonstiges
Zusätzliche Materialien, Vorlagen und kleinere Projekte die keinem spezifischen Modul zugeordnet sind.

## Nutzung

Jedes Unterverzeichnis enthält eine eigene README-Datei mit detaillierten Informationen zum jeweiligen Projekt oder Modul. Die Projekte sind so organisiert, dass sie leicht nachvollziehbar und wiederverwendbar sind.

## Hinweise

Die Projekte wurden im Rahmen meines Studiums erstellt und dienen hauptsächlich Lernzwecken. Bei Fragen oder Anregungen stehe ich gerne zur Verfügung.
