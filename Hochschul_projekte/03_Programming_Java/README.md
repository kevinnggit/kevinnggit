## Beschreibung
Dieser Bereich widmet sich der **Objektorientierten Programmierung (OOP)** mit Java. Er enthält eine Sammlung von Übungsaufgaben, grundlegenden Algorithmen und vollständigen Anwendungen.

## Projektstruktur

- **Basics/**: Enthält grundlegende Übungen und Einführungsprojekte (`prog1`). Hier werden Konzepte wie Datentypen, Kontrollstrukturen und einfache Klassen behandelt.
- **OOP_Concepts/**: Vertiefende Beispiele zur Objektorientierung (`OOP`). Fokus auf Vererbung, Polymorphie, Kapselung und Abstraktion.
- **Battleship_Game/**: Ein vollständiges "Schiffe Versenken" Spiel. Dieses Projekt dient als Praxisbeispiel für die Anwendung komplexer Logik und Interaktion in Java.

## Highlights
- **Schiffe Versenken (Battleship_Game)**: Eine komplette Implementierung des klassischen Spiels. Der Code demonstriert, wie man Spiellogik, Spielfeldverwaltung und Benutzereingaben sauber strukturiert.

## Voraussetzungen
- **Java JDK**: Version 8 oder höher wird empfohlen.
- **IDE**: IntelliJ IDEA, Eclipse oder VS Code für die Entwicklung.
