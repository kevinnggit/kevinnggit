## Beschreibung
Dieser Ordner enthält Projekte aus dem Bereich **Data Science** und **Statistik**. Der Fokus liegt auf der Analyse von Datenverteilungen, statistischen Tests und der Visualisierung von Ergebnissen.

## Projekte

- **Distribution_Analysis/**: (`PyCharmMiscProject`) Ein Projekt zur Analyse diskreter und stetiger Verteilungen. Es enthält Skripte zum Laden, Verarbeiten und Visualisieren von Datensätzen.
    - **Jupyter Notebooks**: Interaktive Analysen und Dokumentation der Ergebnisse.
    - **Python Skripte**: Wiederverwendbare Code-Module für Datenverarbeitung.

## Technologien
- **Python**: Hauptsprache für die Analyse (Libraries: pandas, numpy, matplotlib, scipy).
- **R**: Vereinzelt genutzt für statistische Spezialbereiche.
- **Jupyter**: Für explorative Datenanalyse.

## Installation & Setup
Es wird empfohlen, eine virtuelle Umgebung (venv oder conda) zu nutzen.
```bash
pip install -r requirements.txt # falls vorhanden
# oder
pip install numpy pandas matplotlib scipy jupyter
```
