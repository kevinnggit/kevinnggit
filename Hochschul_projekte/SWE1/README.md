# Software Engineering 1

Dieses Verzeichnis enthält Projekte und Übungen aus dem Kurs Software Engineering 1. Der Fokus liegt auf grundlegenden Konzepten der Softwareentwicklung, HTML-Entwicklung und Bash-Scripting.

## Projekte

### step-project.v1 und step-projekt.v2
Verschiedene Iterationen eines Projekts, das die schrittweise Entwicklung einer Webanwendung demonstriert. Diese Versionen zeigen die Evolution und Verbesserung des Codes über verschiedene Entwicklungsphasen hinweg.

### swe1-project.bash.v1
Ein Projekt mit Bash-Scripting, das grundlegende Automatisierungskonzepte und Shell-Programmierung behandelt.

### HTML-Vorlagen
Das Verzeichnis enthält verschiedene HTML-Seiten für eine Ticket-Buchungsanwendung:
- `index.html` - Startseite
- `login.html` - Login-Formular
- `register.html` - Registrierungsseite
- `forgetpwd.html` - Passwort-Wiederherstellung
- `main-page.html` - Hauptseite nach Login

## Lernziele

Die Projekte in diesem Modul vermitteln:
- Grundlagen der Webentwicklung mit HTML
- Strukturierung von Webanwendungen
- Bash-Scripting für Automatisierung
- Versionskontrolle und iterative Entwicklung

## Technologien

- HTML5
- Bash
- Git
