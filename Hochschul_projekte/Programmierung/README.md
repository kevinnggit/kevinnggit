# Programmierung

Dieses Verzeichnis enthält verschiedene Programmierprojekte, hauptsächlich in Java. Die Projekte decken objektorientierte Programmierung und praktische Anwendungen ab.

## Struktur

### Java
Sammlung von Java-Projekten und Übungen:
- **JavaPj**: Verschiedene kleinere Java-Projekte und Übungsaufgaben
- Grundlegende Java-Programme und Algorithmen
- Objektorientierte Designmuster

### Schiffe
Ein Projekt zum Thema Schiffsverwaltung oder -simulation. Demonstriert praktische Anwendung von objektorientierten Konzepten.
